# Check_DOIs
A python script to extract DOIs from a reference section and check whether DOIs are accessible in general.

1. Open the script in VS Code or Positron.
2. Put your (institutional) E Mail at the top of the script
3. Run the Script:
   * It will ask to paste the whole Reference section
   * It will than extract all DOIs and check whether they are accessible

4. Output: The script will print a numbered list of DOIs with their accessibility status and, if accessible, the paper title.
